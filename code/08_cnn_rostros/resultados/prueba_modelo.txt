TAREA 8. CNN DE ROSTROS

Entrenamiento ejecutado con las 4000 imagenes del dataset compartido:
- Entrenamiento: 3200 imagenes.
- Validacion: 800 imagenes, separadas por clase con semilla 42.
- Epocas: 15.
- Exactitud de validacion del modelo guardado: 91.125%.
- Perdida de validacion: 0.250655.

Se incluyen modelo_propia.keras, clases_propia.json, metricas, historial,
matriz de confusion, particiones de imagenes y curvas del entrenamiento.
La CNN se entreno en este proyecto; el modelo no se copio del companero.

Para repetir el entrenamiento utilizado:
python code/08_cnn_rostros/entrenar_propia.py --epocas 15

Para usar el modelo con la webcam:
python code/08_cnn_rostros/en_tiempo_real_propia.py

Para probar sin camara con una imagen de rostro ya recortada:
python code/08_cnn_rostros/en_tiempo_real_propia.py --imagen RUTA_A_LA_FOTO

Se comprobo la carga del modelo guardado y la inferencia sobre una imagen de
validacion de angel: etiqueta angel, confianza 0.99999976.
La prueba con webcam y su video propio quedan pendientes de hacer manualmente.

LIMITES DEL RESULTADO
La separacion es por imagen. Fotografias de una misma sesion pueden estar en
entrenamiento y validacion: el 91.125% no demuestra el resultado en sesiones
nuevas ni en otras condiciones de luz. La salida Desconocido usa un umbral
de confianza; no garantiza rechazar todas las personas ajenas al dataset.
